# Vision

This app lets coding agents write original songs as files.

Each song file is expressive enough for an agent to compose music that sounds great: real instruments, many genres, strong arrangements, nuanced performance, and polished playback. The browser reads that file, plays the song, and renders a visualization that looks spectacular.

The visualization is not decorative background motion. It is perfectly synchronized to the song: timing, sections, dynamics, beats, instrumentation, and musical moments all shape what appears on screen.

The app should feel like a serious creative instrument for agent-authored music: agents write the file, the browser performs it, and the result feels musical, visual, original, and alive.

There is a dedicated skill that teaches agents how to write excellent song files for this app.

The browser experience should run smoothly, reliably, and beautifully.

This document is the fixed product vision. Do not edit it after creation; use separate progress, gap, or planning documents to track what has changed.
